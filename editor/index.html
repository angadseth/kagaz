Put something on the page.

Text, images, a signature, highlights, whiteout, shapes and freehand drawing — placed where you want them and baked into the file when you save.

Drop your PDF here

or click to choose one from your device

  • Rewrite the text that is already there. Pick Edit text and click any line: it becomes editable in place, at the same size and in the same face the document uses.
  • Nothing uploads. The file is opened, edited and saved in this tab.
  • No quality is lost. Everything is drawn as vector text and shapes straight onto the original page — nothing is turned into an image, at any zoom, so the saved file is exactly as sharp as the one you opened.
  • Where it is imperfect: a rewritten line is covered and redrawn, so a page with a patterned background behind the text can show the patch. Plain backgrounds — which is most documents — come out seamless.
